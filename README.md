# Post-Quantum Cryptography for IoT and Lightweight Environments

Research paper exploring the feasibility of Post-Quantum Cryptography (PQC) in resource-constrained IoT and embedded systems.

## Topics Covered

* ML-KEM (Kyber)
* ML-DSA (Dilithium)
* FALCON
* SLH-DSA (SPHINCS+)
* ASCON Lightweight Cryptography
* PQC performance on ARM Cortex devices
* Memory, energy, and bandwidth constraints
* Hybrid PQC and KEMTLS

## Abstract

This paper surveys recently standardized NIST post-quantum cryptographic algorithms and evaluates their practicality for lightweight IoT environments. The study focuses on implementation challenges, hardware limitations, protocol overhead, and real-world deployment considerations for constrained devices.
